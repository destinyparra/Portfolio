CNC Drawing Machine

A custom desktop CNC drawing machine built from the ground up, combining mechanical design, embedded electronics, motion control, and software development.

Overview

I designed and built this CNC drawing machine as a hands-on electromechanical project exploring how software can control real-world motion. The machine uses a GRBL-controlled Arduino system to translate digital toolpaths into precise movement across multiple axes.

In addition to building the physical machine, I developed JavaScript-based image-processing and toolpath-generation workflows that convert raster images into CNC-compatible paths and generate machine-ready G-code.

Technical Highlights

  • Designed and assembled the CNC motion system using NEMA 17 stepper motors, GT2 belt drives, MGN12 linear rails, linear bearings, and chromed steel guide rods.
  • Integrated an Arduino Uno, CNC Shield, TMC2208 stepper drivers, limit switches, and cooling system into a GRBL-based motion-control platform.
  • Developed JavaScript image-processing and toolpath-generation pipelines to convert raster images into CNC-compatible paths and automatically generate G-code.
  • Transmitted and executed G-code using ChiliPeppr and Serial Port JSON Server.
  • Calibrated steps-per-millimeter, acceleration, travel speed, homing behavior, and axis direction to improve positioning accuracy and repeatability.
  • Troubleshot problems across the software, electrical, and mechanical layers, including motor control, driver configuration, axis alignment, wiring, and toolpath execution.

How It Works

A source image is processed by software to identify the paths that the machine should draw. These paths are converted into G-code, which contains movement commands and coordinates for the CNC controller.

The G-code is sent to an Arduino Uno running GRBL through ChiliPeppr and Serial Port JSON Server. GRBL interprets the commands and controls the stepper motors through the CNC Shield and TMC2208 drivers, translating the digital coordinates into physical X and Y movement.

Build Log

The project has gone through several iterations involving frame assembly, motor installation, belt tensioning, wiring, driver configuration, GRBL calibration, limit-switch setup, and software testing.

As the machine developed, I tested each subsystem independently before integrating everything into the complete motion-control system.

Troubleshooting

Building the machine required diagnosing issues across both hardware and software. I worked through problems involving motor direction, stepper-driver configuration, mechanical alignment, axis movement, GRBL settings, and G-code behavior.

Testing and recalibrating the system allowed me to progressively improve motion accuracy, reliability, and drawing quality.
